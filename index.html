4. while True = Ngulang Tanpa Batas

import random
angka_rahasia = random.randint(1, 10)
while True:
    tebakan = int(input("Tebakan lu: "))
    if tebakan == angka_rahasia:
        print("MENANG!")
        break
    elif tebakan < angka_rahasia:
        print("KECILAN!")
    else:
        print("KEGEDEAN!")
FUNGSI: Ulang terus sampe break. Ini fondasi BRUTE FORCE - hacker nebak password diulang terus sampe bener!
